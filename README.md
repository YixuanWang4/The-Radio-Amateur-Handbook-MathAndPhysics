# 业余无线电实用数学物理

> 电台里的数学与物理：写给想弄明白天线、馈线、传播与设备原理的短波爱好者。

本书用高中代数、三角、对数和一点复数，解释业余无线电里最常遇到的“为什么”：dB 到底怎么读、驻波表为什么不能判断效率、馈线损耗怎样进入链路预算、天线增益与有效面积从哪来、噪声底和灵敏度是什么关系、传播预测里的数字是怎样估出来的。

- **状态**：修订稿 v0.6.0（2026-10）
- **规模**：273 页（A5）、正文约 7.76 万汉字、51 幅插图、45 张表、93 道分级习题（附答案）
- **下载**：[最新 Release](https://github.com/OWNER/REPO/releases/latest)（把 `OWNER/REPO` 换成实际仓库地址；PDF 与 Word 只在 Releases 提供）

## 适合谁

- 刚入门、有设备但还说不清“为什么”的短波爱好者；
- 想自己算尺寸、估链路、判断仪表读数是否可信的进阶爱好者；
- 愿意用一点数学把经验说法还原成可验证理由的读者。

**不写**：电磁场理论的完整推导、功放/收发信机维修、商品评测与报价、法规与执照条款的逐条解释。

## 如何构建

源稿是根目录的 Markdown；DOCX/PDF 均由脚本生成，不要手改构建产物。

```bash
python -m pip install -r requirements.txt

# 1) 生成插图（需要中文字体；可用 FIG_FONT 指定字体文件）
python tools/figs_part1.py
python tools/figs_part2.py

# 2) 生成全书 DOCX 与 PDF（输出到 build/）
python tools/build_book.py
```

- `build_book.py` 依次完成：逐章 DOCX → 合书 → 目录页码校准 → PDF。
- 生成 PDF 需要 LibreOffice Kit。可用环境变量指定：`DSH_NODE`（node 可执行文件）、`DSH_OFFICE_CLI`（`libreoffice-kit` 的 `cli.js`）；找不到时脚本仍可生成 DOCX，但会跳过 PDF。
- 只改某一章时，可直接 `python tools/md2docx.py 08-第07章-传输线.md build/单章.docx` 预览。

检查脚本（不生成文件）：

```bash
python tools/style_check.py --strict      # 语体/字数/禁用词
python tools/structure_check.py           # 章节结构、图表编号
python tools/density_check.py --strict    # 正文数字密度
python tools/final_check.py               # 成书结构（需先 build）
python tools/check_pages_all.py           # 逐页墨迹比例（需先 build）
```
